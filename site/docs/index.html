Good to know before you start

The toolkit is one small fieldkit core plus the tools you add: fieldkit plugin add xray puts a tool on the machine, and the plugins page covers removal, updates, install sources, and writing your own. From a repo checkout, uv sync installs the core and all eight tools editable, which is why the examples in these docs use uv run fieldkit <tool>.

If you would rather point and click, fieldkit serve starts a local web hub at http://127.0.0.1:8765. File tools provide their drag-and-drop workbenches, netwatch opens its local control room, and awcp checks a dropped WorkloadSpec. Tools you have not added sit dimmed with their plugin add command on the card.

About the sample output Every output snippet in these docs comes from running the printed command against the repository's examples/ files. Snippets are abridged: trimmed for width and length, never invented. The netwatch product screenshot uses generated sample evidence and is labelled separately; it does not depict customer traffic or claim usage metrics.
