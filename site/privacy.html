Privacy note

The short version: this site does not set cookies, run analytics, accept uploads, create accounts, or collect information through a form.

Effective August 7, 2026

What this site collects

Nothing directly. There are no analytics scripts, advertising pixels, session-replay tools, forms, account systems, or newsletter fields. The site does not use local storage or cookies.

Hosting logs

The hosting provider may process ordinary request information such as an IP address, browser details, requested path, and timestamp to deliver and protect the site. FDE Tools does not add its own tracking layer or use those logs for advertising.

Links to other sites

Links to GitHub and other sites take you outside FDE Tools. Those services have their own privacy practices. Nothing is sent to them merely by loading this page; the site embeds no third-party content.

Your data choices

There is no site account or profile to access, correct, export, or delete. The command-line tools write their reports and working data on the machine where you run them. The optional network actions are described below.

Netwatch is a local relay for a command you explicitly supervise. It opens only that command's requested destinations allowed by the selected policy, stores metadata in a local SQLite file, and sends no telemetry of its own. Its dashboard reads that local evidence and keeps its managed policy on the same machine. Mutation controls work only from a direct loopback browser; a non-loopback view is read-only. Tell's optional detector adapters need configured vendor keys and explicit authorization: --remote for a CLI run, offline=False for Python adapter calls, or the web flow's one-use confirmation for that text and vendor set. The CLI names the destinations before sending text. A third-party detector's handling of that text is governed by its own privacy practices.

The optional local model may download weights when you first enable --ml; it evaluates the draft locally. Installing Fieldkit or adding plugins also retrieves packages. The static website does not trigger any of these actions.

The Netwatch screenshot on this website contains generated sample evidence. It does not contain customer traffic, prompts, command arguments, or product-usage telemetry, and the page does not connect to a running Netwatch installation.

This static documentation site is maintained by the Fieldkit contributors. For project questions, use the repository’s issue tracker. For a disclosure involving sensitive information, follow the private reporting route in the repository’s security policy. Do not include private data in public issues.
