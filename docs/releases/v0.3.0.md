# Field Kit v0.3.0

Minor release. The core distribution is `fde-fieldkit`. The `fieldkit` command
and the `fieldkit` Python import are unchanged. All nine Python packages are
versioned together.

v0.3.0 is **not on PyPI**. Install from this GitHub release. Do not
`pip install fieldkit` or `pip install fde-fieldkit`. The PyPI project named
`fieldkit` is unrelated.

## Changes

- The core package name is `fde-fieldkit`. Plugin packages stay
  `fieldkit-<tool>`. The core wheel is `fde_fieldkit-0.3.0-py3-none-any.whl`
  and the core sdist is `fde_fieldkit-0.3.0.tar.gz`.
- PyPI upload is a manually triggered, gated Trusted Publishing workflow
  (`.github/workflows/publish-pypi.yml`). It does not run on push, tag, or
  pull request. The owner steps are in `docs/PYPI_PUBLISHING.md`.
- This release is not a PyPI publication. The install path is the GitHub
  release bundle below.

## Install

Download `fieldkit-0.3.0-wheels.tar.gz` and `SHA256SUMS` from this release.
The bundle includes the `fde-fieldkit` core wheel
`fde_fieldkit-0.3.0-py3-none-any.whl` and the eight plugin wheels. Verify the
bundle, extract it, and install every wheel by explicit local path:

```bash
shasum -a 256 --ignore-missing --strict -c SHA256SUMS
tar -xzf fieldkit-0.3.0-wheels.tar.gz
uv venv --seed --python 3.12 fresh
uv pip install --python fresh/bin/python wheels/*.whl
fresh/bin/fieldkit --version
fresh/bin/fieldkit plugin list
```

`wheels/*.whl` selects every Field Kit wheel by path, including the core.
Later plugin operations use `--wheelhouse wheels`.

Nine wheels, nine source archives, the wheel bundle, and `release-manifest.json`
are covered by `SHA256SUMS`. The manifest records the exact source commit.

A pinned checkout of the v0.3.0 tag also works:

```bash
git clone --branch v0.3.0 https://github.com/myrrazor/fde-fieldkit.git
cd fde-fieldkit && uv sync --locked --all-packages
```
