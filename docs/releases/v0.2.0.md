# Fieldkit 0.2.0

Local toolkit for forward-deployed engineers: profile a dump, replace detected
PII, build a demo, explain a diff, write Friday status, inspect a draft, watch
where an agent connects, or check an AI workload spec.

**Python 3.12 or newer. Not on PyPI.** The PyPI project named `fieldkit` is
unrelated. Install our wheels by explicit local path.

Assets: https://github.com/myrrazor/fde-fieldkit/releases/tag/v0.2.0
Website: https://fde-tools-review.vercel.app
Source: https://github.com/myrrazor/fde-fieldkit
Docs fallback: `site/` in the repository

## Install from the wheel bundle

Download
[fieldkit-0.2.0-wheels.tar.gz](https://github.com/myrrazor/fde-fieldkit/releases/download/v0.2.0/fieldkit-0.2.0-wheels.tar.gz)
then:

```bash
tar -xzf fieldkit-0.2.0-wheels.tar.gz
uv venv --seed --python 3.12 fresh
uv pip install --python fresh/bin/python wheels/*.whl
fresh/bin/fieldkit --version
fresh/bin/fieldkit plugin add xray --wheelhouse wheels
```

`wheels/*.whl` selects every Fieldkit wheel by path, including the core. The
archive also unpacks `INSTALL-0.2.0.txt` and a synthetic `examples/customers.csv`.
`--wheelhouse` selects Fieldkit wheels only; other dependencies may still use a
package index. It is not a complete offline bundle.

## Pinned source checkout

```bash
git clone --branch v0.2.0 https://github.com/myrrazor/fde-fieldkit.git
cd fde-fieldkit
uv sync --locked --all-packages
uv run fieldkit --help
uv run fieldkit xray examples/customers.csv
```

## Checksums

`SHA256SUMS` lists 20 assets (18 distributions, the wheel bundle, and
`release-manifest.json`). It does not list itself.

```bash
shasum -a 256 -c SHA256SUMS
```

If you downloaded only the bundle:

```bash
shasum -a 256 --ignore-missing --strict -c SHA256SUMS
```

## Limits

- Local by default. No telemetry.
- Detector hits are not a guarantee. Scrub can miss values. Mimic specs can
  keep non-PII source values and distributions.
- Tell remote adapters need keys plus `--remote` / `offline=False` / one-use
  web confirmation. Keys alone never send text.
- Netwatch relays only traffic the supervised command sends through its
  loopback proxies under the selected policy. It is not a system firewall.
- Inputs are capped at 50 MB (`MAX_DATASET_BYTES`).
- awcp never calls a model or a control plane.
- Not on PyPI. Do not `pip install fieldkit` from an index.
- `--wheelhouse` is not an air-gap installer for third-party dependencies.
