# Field Kit v0.2.1

A stability and correctness release for the local CLI, web hub, and eight plugins.
All nine Python packages remain versioned together. This is a GitHub release,
not a PyPI publication; the PyPI project named `fieldkit` is unrelated.

## Changes

- Heavy hub work runs away from the event loop, with bounded admission, fair
  dispatch, cancellation, and clean shutdown. Interrupted jobs return HTTP 499.
- Faster large-input profiling and writing-pattern scoring; improved mixed-offset
  date handling and secret masking in quoted JSON, markup, and shell text.
- Clear CSV/TSV parse errors, validated Excel sheet selection and queue IDs,
  and close-match suggestions for unknown CLI commands.
- XLSX inflation verifies declared sizes and enforces the 50 MB input cap.
- YAML alias expansion is bounded; alias-free workload specs retain normal support.
- AWCP eval now writes `result.json` to `~/.fieldkit/awcp-artifacts`. Existing
  `./.awcp-artifacts` files stay in place; copy them or use `--artifact-dir`.
- Updated Field Kit branding and public site: https://fde-fieldkit.vercel.app.

## Install

Download `fieldkit-0.2.1-wheels.tar.gz` and `SHA256SUMS` from this release.
Verify the bundle, extract it, and install every wheel by explicit local path:

```bash
shasum -a 256 --ignore-missing --strict -c SHA256SUMS
tar -xzf fieldkit-0.2.1-wheels.tar.gz
uv venv --seed --python 3.12 fresh
uv pip install --python fresh/bin/python wheels/*.whl
fresh/bin/fieldkit --version
fresh/bin/fieldkit plugin list
```

Nine wheels, nine source archives, the wheel bundle, and `release-manifest.json`
are covered by `SHA256SUMS`. The manifest records the exact source commit.

## Historical secret-scan triage

The seven findings from commit `1a696e33cd72ce60bb92c1820e6f0c80cdeb0460`
are confined to `test_quoted_json_tag_and_backtick_secrets_are_masked` in
`tests/test_core_pii.py`. The test passes literal strings to the detector and
asserts that the scrubber removes them; it does not authenticate or make network
calls. The values are the SHA-256 prefix of the word `test`, constructed
mixed-case/sequence strings, a deliberately incomplete JWT example with a
synthetic signature, the AWS documented `EXAMPLEKEY`, and a constructed GitHub
prefix fixture. Duplicate findings include the same fixture in expected output.
No usable credential is present in these findings.

`.gitleaksignore` records only those seven exact commit/path/rule/line
fingerprints. The full-history scan and default detection rules remain enabled;
new findings are not exempted. Never substitute real credentials into fixtures.

The suite remains local by default, with existing explicit consent for optional
Tell adapters, model downloads, package installs, and Netwatch's supervised relay.
