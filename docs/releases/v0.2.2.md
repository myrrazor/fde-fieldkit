# Field Kit v0.2.2

A dependency-only security release. The lockfile picks up fixed versions of
three dependencies; there are no code or behavior changes. All nine Python
packages remain versioned together. This is a GitHub release, not a PyPI
publication; the PyPI project named `fieldkit` is unrelated.

## Changes

- filelock 3.32.0 → 4.2.1 (#13): CVE-2026-112908, CVE-2026-112909,
  CVE-2026-112910, CVE-2026-112911, CVE-2026-112915, CVE-2026-112935,
  CVE-2026-112939.
- certifi 2026.6.17 → 2026.10.19 (#12): PYSEC-2026-4320.
- setuptools 83.0.0 → 84.2.1 (#15): GHSA-xmj3-9gf7-h52w.

## Install

Download `fieldkit-0.2.2-wheels.tar.gz` and `SHA256SUMS` from this release.
Verify the bundle, extract it, and install every wheel by explicit local path:

```bash
shasum -a 256 --ignore-missing --strict -c SHA256SUMS
tar -xzf fieldkit-0.2.2-wheels.tar.gz
uv venv --seed --python 3.12 fresh
uv pip install --python fresh/bin/python wheels/*.whl
fresh/bin/fieldkit --version
fresh/bin/fieldkit plugin list
```

Nine wheels, nine source archives, the wheel bundle, and `release-manifest.json`
are covered by `SHA256SUMS`. The manifest records the exact source commit.
