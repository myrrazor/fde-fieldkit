# WP14 — awcp: local WorkloadSpec checks, diffs, and golden evals

`fieldkit-awcp` is the eighth installable Fieldkit plugin. It ships the honest
local slice of AWCP: spec validation, fingerprinting, categorized diffs, and
golden-suite scoring. It does not call a model, run promptfoo, or provide a
control plane.

## Files

Plugin package under `plugins/fieldkit-awcp`, registry line, examples under
`examples/awcp/`, site docs page `site/docs/awcp.html`, and the usual README /
check_site / hub card wiring.
