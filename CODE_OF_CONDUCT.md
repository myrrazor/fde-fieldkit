# Code of conduct

Fieldkit welcomes people with different backgrounds, experience, and viewpoints.
Everyone should be able to ask a question, report a bug, or contribute without
being harassed or having private information exposed.

Be considerate and specific. Critique the work, explain disagreements, respect
people's boundaries, and accept corrections. Credit other people's contributions.

Harassment, threats, discriminatory insults, unwanted sexual attention, publishing
someone's private information, and repeated disruption are not acceptable. These
rules apply in repository discussions, issues, pull requests, and project spaces.
They also apply when someone represents the project elsewhere.

Maintainers may edit or remove harmful content, close a discussion, restrict
participation, or block an account. The response should reflect the conduct and
its impact; maintainers are expected to explain moderation decisions when doing
so will not expose private information or create further harm.

For a private report, use GitHub's **Report content** or **Report abuse** controls
on the relevant content or account. Those reports go to GitHub. For conduct
visible in this repository, maintainers can also be notified in the relevant
issue or pull request without repeating harmful content or private details.
Do not publish evidence containing personal information.

A security vulnerability or privacy leak in the software should instead follow
[SECURITY.md](SECURITY.md).
