fieldkit

●local by default — tell confirms each remote send; netwatch relays only the command you supervise also a CLI: fieldkit --help

One toolkit. The instruments you chose.

For the days you get handed a mystery CSV, a locked-down laptop, and a Friday status deadline. Add or remove tools any time: fieldkit plugin list

01

xray →

Drop in any data file. Get schema, types, null rates, stats, and PII flags in seconds.

fieldkit plugin add xray

 02

scrub →

Pseudonymize detected PII deterministically, then inspect the output before sharing.

fieldkit plugin add scrub

 03

mimic →

Learn a spec from sample data and generate independent lookalike rows for demos.

fieldkit plugin add mimic

 04

datadiff →

Diff two dumps: schema changes, row-level adds and edits, category and numeric drift.

fieldkit plugin add datadiff

 05

debrief →

Log wins and blockers as they happen. Render a stakeholder-ready weekly status.

fieldkit plugin add debrief

 06

tell →

Paste a draft. See every AI tell — phrase tells, robot rhythm, em-dash clusters — then strip them out.

fieldkit plugin add tell

 07

netwatch →

Run an AI coding agent through local proxies. See destinations, counts, and policy decisions.

fieldkit plugin add netwatch
